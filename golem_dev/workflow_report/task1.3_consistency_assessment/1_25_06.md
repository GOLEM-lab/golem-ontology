	To enforce that textual features and character features are assigned only to the appropriate domain classes, two `owl:allValuesFrom`restrictions on `GP0_has_feature` were added.

	```turtle
	crm:E89_Propositional_Object rdfs:subClassOf
    [ rdf:type owl:Restriction ;
      owl:onProperty golem:GP0_has_feature ;
      owl:allValuesFrom golem:G18_Textual_Feature ] .

	golem:G1_Character rdfs:subClassOf
    [ rdf:type owl:Restriction ;
      owl:onProperty golem:GP0_has_feature ;
      owl:allValuesFrom golem:G17_Character_Feature ] .
      
    golem:G17_Character_Feature owl:disjointWith golem:G18_Textual_Feature .  
    ```
